# Projetos-Python-Metodologia-42

Repositório de aprendizado de Python seguindo (uma adaptação de) a metodologia 
da Escola 42: aprendizado por projeto, sem aulas, sem respostas prontas.

## O que é a metodologia 42

A 42 é uma escola de programação sem professores, sem aulas expositivas e sem 
mensalidade. O aprendizado acontece assim:

- **Subject, não aula**: você recebe o enunciado de um projeto — objetivo, 
  regras, restrições — e precisa descobrir sozinho como resolver.
- **Peer Learning**: quando trava, troca com outro aluno, não recorre a gabarito.
- **Correção por pares**: ao terminar, outro aluno avalia seu código ao vivo, 
  testa casos extremos e questiona suas decisões — você defende suas escolhas.
- **Moulinette**: testes automatizados rodam o código contra centenas de casos, 
  incluindo os que você nem previu.
- **Progressão por projeto**: não existe "módulo de loop" ou "módulo de POO" — 
  cada projeto exige o que for necessário pra resolvê-lo, na ordem que a 
  necessidade dita.
- **Norm**: padrão de código rígido (nomes, tamanho de função, estilo) — 
  código "funciona" não é suficiente, tem que ser limpo.

## Como adaptei isso aqui

Não tenho acesso à 42 nem a peers reais, então simulei essas partes com um 
agente de IA configurado para:
- me dar subjects sem explicação prévia ou dica de implementação
- responder dúvidas com perguntas, não respostas
- fazer o papel de peer evaluator ao final de cada projeto
- gerar uma bateria de testes (moulinette) pra eu validar sozinho
- cobrar um padrão de código (norm) definido no início
